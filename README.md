# Компьютерные сети и сетевые службы в Linux
_на примере Alt Linux_
### Стек
- VMWare Workstation 22H2
- Virtual Network Editor
- ОС: Альт Сервер 11.1, Альт Рабочая станция K 11.4
### Схема стенда
#### Сетевые адаптеры

| Имя сети | Тип | DHCP | Подсеть | Назначение |
| :---: | :---: | :---: | :---: | :---: |
| VMnet0 | Host-only| - | 192.168.100.0/24 | Локальная сеть (loc) |
| VMnet1 | Host-only| - | 192.168.200.0/24 | DMZ |
| VMnet2 | Host-only| - | 10.0.0.0/24      | Внутренняя (inet) |
| VMnet8 | NAT | Enabled | 192.168.254.0/24 | Выход в интернет |

#### Характеристики виртуальных машин
| ВМ |    ОЗУ    | Ядра | Диск | Сетевые адаптеры (интерфейс → VMnet) |
| :---: | :---: | :---: | :---: | :---: |
| alt-srv1 | 3 Гб | 2 | 30 Гб | ens33→VMnet8, ens34→VMnet0, ens35→VMnet1, ens36→VMnet2 |
| alt-srv2 | 3 Гб | 2 | 30 Гб | ens33→VMnet2 |
| alt-srv3 | 3 Гб | 2 | 30 Гб | ens33→VMnet1 (позже bridge) |
| alt-srv4 | 3 Гб | 2 | 30 Гб | ens33→VMnet2 |
| alt-ws1 | 4 Гб | 2 | 40 Гб | ens33→VMnet0 |
| alt-ws2 | 4 Гб | 2 | 40 Гб | ens33→VMnet2 |
